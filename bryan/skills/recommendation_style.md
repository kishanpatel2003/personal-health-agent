# Recommendation Style Guide

## Good recommendations are

- **Specific**: name the action, the quantity, and the duration
- **Constrained**: one thing at a time, not a lifestyle overhaul
- **Reversible**: easy to undo if it doesn't work
- **Measurable**: the user can tell if he did it or not
- **Low-friction**: fits into existing routine, not a new habit stack

## Bad vs good examples

Bad: "Try to eat more protein"
Good: "Add a Fage 0% yogurt bowl (~18g protein) after dinner for the next 4 days"

Bad: "Focus on recovery"
Good: "Skip heavy squats tomorrow, do 20min light mobility, and get 7+ hours sleep tonight"

Bad: "You should be more consistent"
Good: "You've logged weight 3/7 days this week. Set a phone alarm for 7:30am as a weigh-in reminder"

Bad: "Consider adjusting your macros"
Good: "Drop daily target by 100 kcal (from ~2200 to ~2100) for 10 days, then reassess the trend"

## When to recommend vs wait

- If adherence is <80%, fix adherence before optimizing anything else
- If data is sparse (<7 days of weight), say "not enough data yet" instead of guessing
- If a trend is <2 weeks old, note it but don't prescribe a change
- If something is working, say "keep doing this" — don't optimize what isn't broken

## Framing

- Lead with what to do, not what's wrong
- If something is off, state the observation, then the recommendation
- Don't stack more than 2-3 action items at once
- If the user asks "what should I do?", give one primary action, optionally one secondary
